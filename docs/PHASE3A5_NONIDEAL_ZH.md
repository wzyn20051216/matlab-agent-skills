## 0. 结论摘要

### 0.1 一句话结论

**DUAL-B 的 7/7 是真实的，但它成立在一组相当窄的假设上；其中两条假设在本轮被打破。**

- **成立的部分**（有新证据）：离散实现（ZOH + 1 拍计算延迟）下 7/7 仍成立；加上一条与任务书量级相当的非理想传感器链后 7/7 仍成立；**开关级模型下 7/7 也成立**——但要求「周期边界采样 + 半纹波补偿」，而这是本轮才发现的必要条件。
- **被打破的部分**：(1) **2 拍计算延迟下全部失稳**（极限环，非指标退化）；(2) **中点采样 + 1 拍延迟失稳**——采样相位不是自由选择，是稳定性参数。
- **唯一还需要外置硬件**：负载电流传感器。它的可用窗口是 **带宽 ≥ 5 kHz、延迟 ≤ 1 拍**；低于此值 S5 直接失守。

### 0.2 验证等级状态（这是本报告的主表，任何引用都必须带等级）

| 等级 | 模型内容 | DUAL-B 结果 | 状态 |
|---|---|---|---|
| **A** 理想连续平均 | 连续 PI + 理想 iLoad，无采样 | **7/7** | 已完成（Phase 3A.4，84 次 Simulink） |
| **B** 理想离散平均 | 50 kHz 采样、ZOH、1 拍计算延迟 | **7/7** | 本轮完成（21 组，0/1/2 拍扫描） |
| **C** 离散平均 + 非理想传感器 | 10 kHz 带宽、1 拍延迟、+2% 增益、0.1 A 偏置、σ=0.02 A 噪声、LSB 0.02 A | **7/7**（裕度大幅缩小） | 本轮完成（21 组） |
| **D** 开关级 | 真实 PWM 比较、纹波、二极管压降、Ron、ESR、ZOH 调制、1 拍延迟 | **7/7** | 本轮完成（28 组） |
| **E** 真实硬件 | — | **SKIP** | 无硬件 |

> **A 级通过不等于 D 级通过。** 本轮的 D 级是独立执行的，不是从 A 级推断的；
> 而且 D 级的通过依赖一个 A 级模型里根本不存在的设计选择（半纹波补偿）。

## 1. Task 0：模型审计

审计脚本 `verify/buck_a5_task0_audit.m`（可一键复现全部数字，产物 `a5_task0_audit.json`）。
审计只读，不改任何原有逻辑；修复在审计确认之后进行，每项都带回归。

### 1.1 A1 — ff=1 时积分器初值重复补偿（已修）

```matlab
% 3A.4 的实现（错）
xe0 = iL0/Kie;          % 只有 ff=0 时才对
```

稳态关系是 `iLref = Kie*xe + ff*iLoad`。`ff=0` 时 `Kie*xe = iL0`，所以 `xe0 = iL0/Kie`；
但 `ff=1` 时 `iLoad` 本身已经是 `iL0`，再令 `xe0 = iL0/Kie` 就等于**把负载电流算了两遍**，
`t=0` 时刻的电流指令是 `2*iL0`。

**实测**：`ff=1` 且 `xe0 = iL0/Kie` 时，`t=0` 处出现 **0.9315 V** 的虚假偏差（`iLref/iL0 = 2.000`）；
改为 `ff=1 → xe0 = 0` 后偏差 **0.0000 V**。

> **为什么上一阶段没暴露**：负载阶跃在 60 ms，启动瞬态早已被外环积分器抹平。
> 这是一个「不影响最终 7/7、但让初值不是稳态」的错误——它不影响结论，但会让任何
> 短时间窗或初值敏感的分析给出错误结果。

### 1.2 A2 — 电流指令限幅在负载前馈之前（已修）

3A.4 的接线顺序是 `iLref = clamp(Kp_e*e + xI)` **然后** `+ iLoad`。
后果：即使饱和，指令仍会随负载电流整块增长，**限幅形同虚设**。

**实测**：`Imax = 6 A` 时，`iLref` 峰值达到 **8.418 A**（超出 40%）。
修复后（先加前馈、再限幅）峰值 **6.000 A**。

### 1.3 A3 — 连续 / 离散 / 解析三者的一致性

| 量 | 连续平均（A） | 离散 0 拍 | 离散 1 拍 | 离散 2 拍 |
|---|---|---|---|---|
| C1 跌落 | −1.377% | −0.985% | **−2.317%** | −0.266%（假值，见下） |
| C1 S5 | 0.103 ms | 0 ms | **0.140 ms** | **NaN（不收敛）** |

**连续模型比 1 拍离散乐观 0.94 pp（约 40%）。** 这不是舍入，是采样延迟的真实代价。
另外 2 拍那一行的跌落「看起来只有 −0.27%」极具欺骗性——它是**极限环**的平均值，
S5 = NaN 才是真相。**任何只看 dip 不看 S5/收敛性的表都会被这一行骗过去。**

### 1.4 A4 — 84 次验收的等级归属（对上一阶段的更正）

`buck_a4_acceptance.m` 用 `build_buck_dual_loop`，该模型：控制器是连续模块、占空比直接进
PWM 比较器、**没有 ZOH、没有采样、没有计算延迟**。审计检索离散块数量：**0**。

因此 Phase 3A.4 的 84 次结果 = **A 级（理想连续平均）**，不是数字实现。
这不是说结果错了，而是说**它证明不了数字实现**，而 3A.4 的报告把「离散 PM」当成了
数字验证的替代品——那是频域指标，不是时域闭环验证。本轮补 B/C/D 三级。

### 1.5 A5 — 电压跌落的「物理下界」用错了初始电流（对上一阶段的更正）

3A.3 给出的下界：

```
R1 = 3Ω   -> −0.390%
R1 = 1.5Ω -> −3.320%   <-- 3A.4 用它论证"DUAL-B 已达下界 82%"
```

用 `buck_dip_floor.m` 复算**同一个阶跃**（3Ω→1.5Ω，ΔI = 4 A）：

| 计算方式 | 下界 |
|---|---|
| 3A.3 的算法（阶跃前电流取 `Vref/R1`，即用**阶跃后**的负载反推初始电流） | −3.320% |
| 正确的算法（阶跃前 `iL0 = Vref/R0 = 4 A`） | **−1.510%** |

3A.3 把阶跃前的电感电流取成了阶跃后的值，于是把「本来就在流 4 A」错当成「从 2.67 A 起跳」，
多算了 1.5 A 的电流缺口，下界被放大了 2.2 倍。

**后果**：DUAL-B 的 −2.69% 不是下界的 82%，而是 **1.78 倍**——S7 还有约 1.8 倍余量，
「已触底、无优化空间」这句话作废。**这条更正对我们自己不利，如实记录。**

## 2. Task 1：真实离散闭环时域仿真

脚本 `verify/buck_a5_task1_digital.m`，模型 `buck_dual_sim.m`（50 kHz 采样 + 数字 PI +
ZOH + 抗饱和 + 双限幅 + 可配置计算延迟），产物 `a5_task1_digital.json`。

### 2.1 延迟对三个判据的影响

| 计算延迟 | 最坏离散 PM | 最坏 GM | 最坏 S5 | 最坏跌落 | 最坏启动超调 | 七工况 |
|---|---|---|---|---|---|---|
| **0 拍** | 60.42° | 22.43 dB | 0.120 ms | −1.906% | 1.31% | **7/7** |
| **1 拍** | 51.25° | 13.00 dB | 0.440 ms | −4.475% | 1.32% | **7/7** |
| **2 拍** | 42.08° | 8.83 dB | **NaN（不收敛）** | 见表下注 | 15.20~18.02% | **0/7** |

- 每增加一拍延迟：**PM 掉约 9.2°、GM 掉约 4.2 dB**。
- 1 拍仍过 S2（51.25°），但**只剩 1.25° 余量**。
- **2 拍不是「变差」，是「不收敛」**：启动超调 15~18%，`settleMs = NaN`。
  实测该工况是 **~4 kHz 的极限环**（`vC` 在 11.97~13.76 V 之间往复，占空比打到两侧限幅）。

### 2.2 为什么 2 拍不能靠「频域还有 42°」蒙混过关

PM = 42° 看起来只是「裕度不足」，但时域已经不收敛。原因是纯积分外环 + 采样延迟在高频段
相位快速下降，PM 这个单一数字无法表达「极限环」这种非线性行为。
**这就是任务书要求「用真实离散闭环时域响应判断，而不是只依赖频域裕度」的原因，
本轮实测印证了它有实质差别。**

### 2.3 延迟预算

| 量 | 实测代价 |
|---|---|
| 1 拍（20 µs） | PM −9.2°，S5 从 0.12 → 0.44 ms（C5） |
| 2 拍（40 µs） | 失稳 |
| **工程结论** | 数字链路（ADC 采样 + ISR 计算 + PWM 更新）**总延迟必须 ≤ 1 个开关周期**，且不得有 1.25° 以外的额外裕度消耗 |

## 3. Task 2：负载电流传感器非理想性

脚本 `verify/buck_a5_task2_sensor.m`，产物 `a5_task2_sensor.json/.png`。
**所有参数都是本轮的工程假设，不是任何真实传感器数据。** 传感器模型：

```
iLoad_true → 一阶带宽极点 → 传输延迟（整数拍） → 增益误差 → 零点偏置
           → 高斯噪声 → ADC 量化 → （可选）故障注入
```

### 3.1 为什么 S5 = 0.155 ms 这件事让传感器变得关键

0.155 ms ≈ **7.75 个开关周期**。前馈通道里任何一个周期的延迟，都会占到恢复时间的 13%。
所以本节不是「补充分析」，而是决定 DUAL-B 能否成立的条件。

### 3.2 逐项敏感度（C1 = 6Ω→3Ω，C5 = 3Ω→1.5Ω）

| 参数 | 取值 | C1 S5 (ms) | C5 S5 (ms) | 判定 |
|---|---|---|---|---|
| **带宽** | ∞ | 0.140 | 0.440 | 基准 |
| | 20 kHz | 0.140 | 0.440 | 无影响 |
| | 10 kHz | 0.100 | 0.440 | 无影响 |
| | 5 kHz | 0.220 | 0.580 | 可用 |
| | 2 kHz | 0.240 | **0.980** | 边缘 |
| | **1 kHz** | 0.880 | **1.300** | **FAIL** |
| **传输延迟** | 0 拍 | 0.140 | 0.440 | 基准 |
| | **1 拍** | 0.440 | 0.720 | 可用 |
| | **2 拍** | 0.600 | **1.040** | **FAIL** |
| | 3 拍 | 0.760 | 1.220 | FAIL |
| **增益误差** | 1.00 | 0.140 | 0.440 | 基准 |
| | 1.02 | 0.280 | 0.460 | 可用 |
| | 1.05 | 0.280 | 0.580 | 可用 |
| **零点偏置** | 0 ~ 1.0 A | **0.140（完全不变）** | **0.440（完全不变）** | 外环积分器吸收 |
| **噪声 σ** | 0.02 A | 0.140 | 0.440 | 可用 |
| | 0.10 A | 0.140 | 0.440 | 可用 |
| | **0.20 A** | **39.34** | **39.34** | **FAIL（进入振荡）** |
| **ADC LSB** | 0 ~ 0.1 A | 0.140 | 0.440 | 几乎无影响 |

### 3.3 从这张表读出的三件事

1. **带宽与延迟是硬门槛，且门槛很陡**：5 kHz 可用、1 kHz 直接失守；1 拍可用、2 拍失守。
   这不是「精度问题」，是「前馈在阶跃瞬间到底有没有及时出现」的问题。
2. **零点偏置完全无影响**——外环积分器把它当稳态误差吃掉了。这条通常被过度担心，
   实测**可以不管**（代价是稳态误差由外环承担，而不是前馈）。
3. **噪声有一个陡峭的悬崖**：σ 从 0.10 A 到 0.20 A，S5 从 0.14 ms 变成 39 ms。
   实测该工况是前馈通道把噪声放大成持续的电流指令抖动，进而激起 LC 谐振。
   **所以前馈通道必须低通滤波，而滤波又会引入延迟——这正是 §3.2 里 1 kHz 失守的原因。**
   这是一个闭环设计矛盾，不是调参能解决的：**需要提高信噪比（更大的分流器/霍尔量程）或
   对前馈单独做陷波，而不是简单加 RC。**

## 4. Task 3：前馈故障与降级

脚本 `verify/buck_a5_task3_faults.m`，产物 `a5_task3_faults.json/.png`。

### 4.1 监督器（supervisor）设计

不增加硬件，用**解析冗余**判故障：控制器已有 `iL` 和 `vC`，因此负载电流可重构

```
iLoad_est = iL - C*dvC/dt
```

判据与去抖：

| 判据 | 阈值 | 去抖 | 理由 |
|---|---|---|---|
| 物理范围 | `[-0.5, 1.25*Vref/1.5]` = [−0.5, 10] A | **立即**（0 拍） | 量程越界是硬件故障，无歧义；迟一拍就多注入 1.6 A 的错误电流 |
| 读数冻结 | 连续 8 拍内极差 < 1e-9 且 `|dvC/dt| > 50` | 3 拍 | 冻结检测本身对噪声敏感 |
| 与重构值偏差 | > 3.0 A | 3 拍 | 微分噪声大，容差必须宽 |
| 恢复 | 连续 20 拍（0.4 ms）正常 | — | 防止抖动 |

**无扰切换（bumpless）**：`iLref = Ki_e*xe + ff*iLoad`。切换 ff 会让指令跳变整个负载电流，
所以切换时同步平移积分器：`xe ← xe ∓ iLoad/Ki_e`，保持 `iLref` 连续。

### 4.2 故障注入结果

| 故障 | 监督器 | 传感器偏差 | 跌落 | S5 | iLmax | 触发/恢复 | 稳定 | 安全 |
|---|---|---|---|---|---|---|---|---|
| 无 | 关 | 0 | −2.317% | 0.140 ms | 6.12 | 0/0 | ✓ | ✓ |
| 无 | 开 | 0 | −2.317% | 0.140 ms | 6.12 | 0/0 | ✓ | ✓ |
| 开路 | 关 | 0 | −6.284% | 1.120 ms | 4.24 | 0/0 | ✓ | ✓ |
| 开路 | 开 | 0 | −6.284% | 1.120 ms | 4.24 | 2/1 | ✓ | ✓ |
| 读数冻结 | 关 | 0 | −6.284% | 1.120 ms | 4.24 | 0/0 | ✓ | ✓ |
| 读数冻结 | 开 | 0 | −6.284% | 1.120 ms | 4.24 | 1/1 | ✓ | ✓ |
| **读数打满** | **关** | **7.02 A** | −6.284% | 1.120 ms | 4.24 | 0/0 | ✓ | **✗** |
| **读数打满** | **开** | **0** | −6.284% | 1.120 ms | 4.24 | 1/0 | ✓ | **✓** |
| 偏置 +2 A | 关/开 | 0 | −2.317% | 0.140 ms | 6.12 | 0/0 | ✓ | ✓ |

| 关断后再开 | — | 0 | −6.284% | 1.120 ms | 4.24 | 1/1 | ✓ | ✓ |

### 4.3 三条结论

1. **监督器唯一不可替代的作用是「读数打满」**：无监督器时传感器偏差 7.02 A，
   安全包络被突破；有监督器时偏差 0，安全包络保持。其他故障即使不监督，
   结果也只是退化为无前馈模式。
   （这一条是本轮修 bug 修出来的：第一版监督器在打满故障下仍让输出冲到 18.65 V，
   因为它用 3 拍去抖、且切换时用的是坏值。改为「量程越界立即跳闸」+「切换用上一次
   实际生效的 iFF」后才正确。）
2. **降级模式的真实性能**：无前馈双环 = **跌落 −6.28%、S5 1.12 ms**。
   稳定、安全、S7 通过（6.28% < 12%），但 **S5 失败**（1.12 > 1.0 ms）。
   按任务书要求如实记录：**降级模式不满足 1 ms 标准，这是设计上接受的性能下降**。
3. **监督器会把「慢但仍然可用」的传感器误判为故障**：延迟 5 拍时，监督器让它退化
   （S5 0.82 → 0.98 ms），而实际上不监督反而更好（0.82 ms）。**容差 3.0 A 偏保守**，
   工程上应放宽到 5~6 A 或改成自适应阈值。

## 5. Task 4：开关级模型

### 5.1 平台选择（如实说明）

- **Simscape Electrical 有授权**：块可解析，`Vdc + Resistor + Electrical Reference +
  Solver Configuration` 网表可成功连线和仿真。
- 但完整变换器在 `-batch` 下反复出现端口/域类型错误（理想 Switch 块的端口语义在批处理
  下无法稳定确定），每次尝试约 1 分钟。**这是排期决定，不是授权限制。**
- 按任务书允许的退路，用 **Simulink 基础模块**搭了真正的开关级模型
  （`build_buck_switching.m`）：瞬时开关节点电压、二极管压降与导通电阻、电感/电容动态、
  ESR、PWM 载波比较、ZOH 调制、可选计算延迟。**它不是平均模型**：`vSW` 在 48 V 与 −0.35 V
  之间逐周期跳变，纹波完整保留。
- Simscape 版本列为后续工作（§7.2）。

### 5.2 为什么必须加 ZOH（一个被掩盖了整整一轮的建模缺陷）

第一版开关模型把连续控制器输出直接与锯齿载波比较。后果：

```
一个周期内 d 从 0.4114 连续滑到 0.3512（控制器在周期内还在动）
记录的平均 duty = 0.3326
由 vSW 实测的真实占空比 = 0.2590
→ 内环被迫维持 0.66 A 的虚假稳态误差（iLref = 2.66 A，而 iL = 2.00 A）
```

正确做法是**每个开关周期锁存一次占空比**（真实 PWM 外设就是这样）。加 ZOH 后
`duty = 0.2554`，与理论值 0.2563（含 Ron、Vf、RL 压降）吻合。

> 这条缺陷在 3A.4 完全不存在——因为 3A.4 用的是平均模型，根本没有载波。
> **它只在「真的去搭开关模型」时才暴露**，这也是 A 级不能替代 D 级的具体例子。

### 5.3 采样相位：本轮最重要的工程发现

`build_buck_switching.m` 的 ADC 在每个周期采样一次 `iL`。**采在哪个相位决定了内环调的是
峰值、谷值还是平均值**：

| 采样相位 | 采到的 `iL`（几何预测） | 实测 `iLref` | 偏差 |
|---|---|---|---|
| 0（周期边界 = 谷值） | 1.384 A | **1.439 A** | −0.56 A |
| 0.125（中点，D≈0.25 时） | 2.000 A | 2.043 A | +0.04 A |
| 0.25（下降沿中部） | 2.215 A | 2.636 A | +0.63 A |

原因很直接：`L=150 µH, 50 kHz` 下的纹波是 **1.23 App 对 2.0 A 直流（62%）**，
三角波的谷值与平均值差半个纹波。

**但把采样点移到中点是有代价的**：它引入额外的 0.125·Ts 环路延迟。

| 配置 | 跌落 | S5 | 启动超调 | 结论 |
|---|---|---|---|---|
| 边界采样 + 0 拍延迟 | −0.76% | 0 ms | 1.67% | 可用（但电流偏差 0.56 A） |
| 边界采样 + 1 拍延迟 | −2.21% | 0.181 ms | 1.71% | **可用** |
| **中点采样 + 1 拍延迟** | −0.29% | **29.99 ms** | **17.30%** | **失稳** |
| 下降沿采样 + 1 拍延迟 | −2.30% | NaN | 11.33% | 失稳 |

**正确解法：边界采样（延迟最小）+ 解析半纹波补偿**

```
dIL/2 = (Vin − Vout)·d·Ts/(2L)
```

它只用控制器已有的量，不需要额外传感。实测补偿后 `iLref = 2.039 A` vs `iL = 2.002 A`
（偏差从 0.56 A 降到 0.037 A），且 1 拍延迟下仍稳定。

> 这一条无法从平均模型推出，也无法从频域裕度推出。**它只能在开关级模型里发现**，
> 而且如果没发现，D 级会给出「电流偏低 28%」这种看起来像「保守」、实际是错的稳态点。

### 5.4 开关级稳态（C1，负载阶跃前）

| 量 | 实测 | 理论 |
|---|---|---|
| `vOut` 平均 | **12.0000 V** | 12 V |
| `vOut` 纹波 | 0.0192~0.0283 Vpp | — |
| `iL` 平均 | 2.000 A | 2 A |
| `iL` 纹波 | **1.23~1.32 App** | 1.42 App（含控制调制） |
| 占空比 | 0.2554 | 0.2563（含 Ron/Vf/RL） |
| 开关节点 | 47.999 V / −0.354 V | Vin − iL·Ron / −(Vf + iL·RonD) |

**开关级独有的两个限幅事实**（在 §6.5 的 D 级表里体现）：

- `iL` 峰值 **12.36~12.41 A > Imax = 12 A**（超出 3%）。因为电流限幅作用在**采样值（谷值）**上，
  真正的峰值还要高半个纹波（约 0.65 A）。**`Imax` 是平均值限幅，不是峰值限幅**；
  若要用作过流保护，必须按「Imax + 半个纹波」重新整定。
- `duty` 在恢复段被打到 **0.050**（S8 的下限本身）。1 拍延迟让电流内环过冲，前馈又把指令
  推得更高，于是占空比瞬间压到下限。这不是失控（随后立即恢复），但 **S8 是零余量通过**。

纹波 1.23 App 对 2 A 直流意味着 **电流纹波率 62%**——这本身就是一个设计缺陷
（一般要求 < 40%），它同时解释了为什么采样相位这么敏感。**这是硬件层面的问题，
不是控制层面的问题**，列入 §7.2 的建议。

### 7.4 是否满足旗舰 Demo 发布条件

**结论：作为「工程案例」满足；作为「产品级 Demo」不满足。**

满足的部分（这是本项目最有说服力的地方）：

- 四级验证（A/B/C/D）全部真实执行，每一级的级差都被量化，**没有把 A 级通过写成 D 级通过**；
- 三个「结论级」缺陷是在验证过程中被自己发现并公开的（等级误标、下界算错、调制器无 ZOH）；
- D 级发现的两个问题是**只有开关模型才能暴露**的（采样相位、半纹波补偿），证明分级验证
  不是形式主义；
- 失败项与降级模式全部保留，没有为了 7/7 修改任何阈值。

不满足的部分（发布前必须解决）：

1. **没有硬件**。一个电源控制器的最终证据只能是实测波形。目前所有 D 级结论仍是仿真。
2. **电流纹波率 62%**。这是硬件设计缺陷，它让控制对采样相位高度敏感；量产必须把 L 提到
   330~470 µH（纹波降到 20~28%）或提高 fs。
3. **前馈依赖一路额外电流采样**，且该传感器的可用窗口（≥5 kHz、≤1 拍、σ≤0.1 A）虽然
   宽松，但**噪声悬崖很陡**（0.1 → 0.2 A 就从 0.14 ms 变 39 ms），工程上必须实测验证。
4. **延迟预算只有 1 拍**。留给 ADC + ISR + PWM 更新的总时间是 20 µs，这在
   150 MHz 级 MCU 上是可行的，但没有实测余量数据。

**给下一阶段的建议优先级**：

| 优先级 | 事项 | 理由 |
|---|---|---|
| 1 | 硬件原型 + 实测 D 级 | 没有它，前三条都只是仿真 |
| 2 | 把 L 提到 330~470 µH 重测 | 消除纹波率 62% 带来的采样敏感性 |
| 3 | 传感器选型 + 实测噪声谱 | 噪声悬崖是唯一「非线性崩塌」的风险点 |
| 4 | Simscape 器件级模型（含反向恢复/结电容） | 基础模块模型不含开关损耗 |
| 5 | L −30% 容差下的采样约束复核 | 当前只测了 L 增大 |
