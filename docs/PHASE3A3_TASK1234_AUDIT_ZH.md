## 2. Task 2：模态 S5 公式审计

### 2.1 三个量的定义（本报告冻结使用）

```
A_tol   = 1% × Vref = 0.120 V          （误差带**半宽**，不是全宽 0.24 V）
σ       = Re(p_LC) < 0    [1/s]        τ = 1/|σ| [s]
S5      = 自阶跃时刻起，|vC−Vref| 进入 ±A_tol 并**此后一直保持**带内的时刻 [ms]
formula = S5_f = ln(A_LC / A_tol) / |σ_LC|
```

**A_LC 有三种互不相同的候选含义**，本报告全部计算并分开列表：

| 符号 | 定义 | 物理含义 |
|---|---|---|
| `A_eig` | `2·|a|`，`a` 为阶跃后闭环 A 矩阵特征分解中 LC 对的系数（初值取**切换时刻真实状态 − 阶跃后稳态**） | 模型给出的 LC 模态包络初值 |
| `A_lsq` | 对实测 0.3–30 ms 段做最小二乘得到的 LC 对系数 `2·|c|` | 数据拟合的模态幅值 |
| `A_env` | 实测振荡**局部峰值**的指数拟合 `A·exp(σ_env t)` 外推到 t=0 | 直接测得的**包络**幅值（含多模态干涉的有效值） |

**只有 `A_env` 是"振荡包络幅值"的字面含义**；`A_eig`/`A_lsq` 是模态分解系数。三者数值不同（§2.3），因此**不能混用**。

### 2.2 单位一致性

内部一律 SI（V, s, rad/s），仅在打印时换算为 %、ms。`A_LC` 与 `A_tol` 同为伏特，`ln` 无量纲，`|σ|` 为 1/s，结果乘 1e3 得 ms。**无隐含的百分比/绝对量混用**。上一轮报告曾用 `A_LC[%]` 代入 `A_tol=1%`，数值上等价，但表述不严谨，本报告统一用伏特。

### 2.3 三种 A 的实际数值（不四舍五入）

| 工况 | 控制器 | `A_eig` V (%) | `A_lsq` V (%) | `A_env` V (%) | `σ_env` (rad/s) | `σ_LC` (rad/s) |
|---|---|---|---|---|---|---|
| C1 | BASE | 1.6805 (14.004) | 1.711 (14.258) | 0.9863 (8.219) | −495.99 | −565.1 |
| C1 | OPT | 0.6216 (5.180) | 0.612 (5.100) | 0.2350 (1.959) | −141.78 | −217.8 |
| C6 | BASE | 3.5262 (29.385) | 3.932 (32.767) | 1.1951 (9.959) | −765.00 | −1293.4 |
| C6 | OPT | 0.9842 (8.202) | 0.951 (7.925) | 0.3936 (3.280) | −217.22 | −296.4 |

**同一工况同一物理现象，`A` 相差最多 3 倍**（C1 OPT：0.622 / 0.612 / 0.235 V）。原因是：

- `A_eig` 与 `A_lsq` 接近（≤2%），因为二者都是同一组极点的线性组合系数——**互相印证**。
- `A_env` 明显更小，因为实测振荡是**多个模态叠加**后的净效果，局部峰值并不等于单一模态的系数。
- `σ_env ≠ σ_LC`：证明确实存在多模态干涉。C1 OPT 的包络按 −141.8 rad/s 衰减，介于 LC 模（−217.8）与慢极点（−82.7）之间。

### 2.4 公式误差（19 个收敛案例）

| 预测通道 | 最大相对误差 | 平均相对误差 | 结论 |
|---|---|---|---|
| `S5_f` 用 `A_eig` + `σ_LC` | **19.43%** | 4.68% | 近似可用 |
| `S5_f` 用 `A_lsq` + `σ_LC` | **16.83%** | 4.39% | 近似可用 |
| `S5_f` 用 `A_env` + `σ_env` | **39.83%** | 13.50% | **不可用** |
| **模态和（精确）** | **0.013%** | 0.001% | **可用** |
| **独立 RK4（精确）** | **0.013%** | 0.001% | **可用** |

**结论：**
- 该公式是**量级估计**，不是精确预测。任何以它为依据的"±0.04%"声明都是错误的。
- 用 `A_env` 反而最差——因为"包络"本身已经被多模态干涉污染，且 `σ_env` 不是任何极点的实部。
- 若必须用公式，应取 `A = A_eig`（或 `A_lsq`）配 `σ = Re(p_LC)`，并接受**约 5% 平均、最坏 20%** 的误差。

### 2.6 未判定与拒绝预测的规则（已实现）

| 条件 | 处理 |
|---|---|
| `S5_meas = NaN`（末点仍越界） | `UNDETERMINED(not converged)` |

## 3. Task 3：模态识别验证

### 3.1 方法

**不能用参考输入阶跃 `T(s)` 的留数**：负载阶跃改变对象参数 R，是**分段系统**。正确做法：

1. 用**自己的 RK4** 从 `X0=[0;0]` 复现 0–60 ms（R=Rpre），得到切换时刻状态 `x_sw`；
2. 取阶跃后闭环 A 矩阵，以 `Δx0 = x_sw − x_ss(Rpost)` 为初值做特征分解；
3. 每个模态对输出电压的贡献为 `V(2,q)·(W·Δx0)(q)·exp(p_q t)`，共轭对取 `2Re(·)`；
4. **必须减去阶跃后稳态**——否则直流工作点 12 V 会混入展开式，使每个系数虚增约 12 V（本轮实际踩到：未减稳态时 C1 BASE 的实极点系数被算成 12.23 V）。

### 3.3 三种"主导"必须区分

| 概念 | 判据 | C1 BASE | C1 OPT | C6 OPT |
|---|---|---|---|---|
| **最慢极点** | `max Re(p)` | −384.9 | **−82.7** | **−86.1** |
| **最大幅值模态** | `max |a|` | −565.1 对（14.0%） | −3250.8 对（6.98%） | −3928.1 对（12.8%） |
| **S5 主导模态** | `max tExit` | −565.1 对（4.67 ms） | −217.8 对（7.55 ms） | −296.4 对（7.10 ms） |

- **三者互不相同。** 最慢极点（积分器）在三个案例中**都不是** S5 主导模态。
- 积分器模态的幅值 0.045%～0.169%，**远低于 1% 误差带**，其 `tExit = 0`——**物理上不可能造成任何越界**。
- 因此"用 `maxRe` 判主导"是错的（3A.1/3A.2 的 D-A6），"用最大幅值判主导"也不对（C1 OPT 的最大幅值是陷波对，但它 0.6 ms 就衰减完了）。

**S5 主导性由 `ln(A/A_tol)/|σ|` 最大者决定**，这正是公式的正确用法——但如 §2.4 所示，用它**定量**只有 5% 量级精度。

### 3.4 多模态叠加时单一指数包络是否适用

**不适用。** 证据：

1. 实测包络衰减率 `σ_env` 与任何极点都不相等：C1 OPT 为 **−141.8**，而 LC 模 **−217.8**、积分器 **−82.7**。
2. 用 `A_env`+`σ_env` 代入公式，误差最大 **39.8%**（§2.4），是三种定义里最差的。
3. C6 BASE 存在两个模态同时超过 1% 带（LC 对 29.4%，实极点 2.38%），单指数公式误差 −19.4%。

**判据**：当第二模态的 `tExit` 与第一模态之比 > 0.8 时，标记 `UNDETERMINED(multi-mode comparable)`。本批 21 组中该判据触发 0 次（比值均 < 0.3），但误差仍达 20%，说明"未被标记"不等于"公式精确"——**公式精度与干涉判据是两件事**。

### 3.5 独立时域验证

用**自己的 RK4**（定步长 1 µs、含占空比限幅与 back-calculation 抗饱和、从 `X0=[0;0]` 完整复现 0–120 ms）对同一分段系统做独立仿真，与 Simulink 记录逐点比较：

| 指标 | 结果 |
|---|---|
| 全部 21 组 `max |ΔvC|`（阶跃后全程） | **0.01444 V**（出现在 C7 未收敛组） |
| 19 个收敛组的 `max |ΔvC|` | **≤ 0.0001 V** |
| S5 的 RK4 vs 实测最大相对误差 | **0.013%** |

**这证明**：① 分段系统建模正确；② 控制器（含抗饱和）实现一致；③ S5 的测量口径与独立实现一致。**模态和、独立 RK4、Simulink 三者互证**。

## 6. 其他发现

### 6.1 `settleMs` 的 1 采样点低估（D-A4，确认）

`step_metrics.m:75`：`m.settleMs = (tv(lastOut) - tv(1))*1e3;` 取的是**最后一个越界样本**的时刻；按用户定义应为"此后常驻带内的第一个样本"，即 `tv(lastOut+1)`。

19 个收敛案例的偏差**恒为 +0.0010 ms**（=1 µs，等于输出步长）。量级 0.02%，**不改变任何 PASS/FAIL**，但定义不严格。建议修正，**不应**据此重算历史结论。

### 6.2 阶跃时刻的重复时间戳

`t` 在 `t=0.060` 处有两个几乎重合的样本（间隔 4.4e-16）。做模态最小二乘时若同时纳入会造成基矩阵病态；本报告的拟合窗口从 0.3 ms 开始，避开该点。

### 6.3 阶跃前状态不是解析稳态

Simulink 的 `X0=[0;0]` 使系统有启动瞬态。60 ms 时 OPT 的 `vC` 仍低于目标 **0.029 V**（C2 为 0.039 V，C4×BASE 因 R=12 不稳定而高 0.396 V）。任何以解析稳态为初值的预测都会引入百分级偏差（实测 C2×OPT 因此偏 8%）。**本报告的 RK4 从 `X0=[0;0]` 完整复现，不在阶跃处重置。**

## 8. 结论与是否进入架构改造

### 8.1 Task 1–4 的确定结论

1. **S5 的计算口径现在是可信的**：严格定义（进入并常驻 ±1% 带）已独立实现，与 `step_metrics` 差异恒为 1 µs；21 组中 19 组 `DETERMINED`、2 组 `UNDETERMINED`（未收敛），**没有把未判定标成 PASS**。
2. **模态识别现在是可信的**：三路独立验证（模态和 / 自写 RK4 / Simulink 记录）在 19 个收敛案例上互差 ≤0.013%（S5）与 ≤0.1 mV（波形）。
3. **公式 `S5 ≈ ln(A_LC/A_tol)/|σ_LC|` 只是量级估计**：平均误差 4.4%–4.7%（用 `A_eig` 或 `A_lsq`），最大 19.4%。**不能用它做 1% 量级的判定**，只能用模态和或直接仿真。
4. **S5 的瓶颈是 LC 谐振环的阻尼与激励幅值**，不是积分器极点（后者幅值 0.045%–0.169%，永不越界）。
5. **S2 与 S5 不冲突**（Pareto 单调）；**S7 与 S5 冲突**（深陷波压 dip 会削弱 LC 阻尼）。
6. **单环 PI+陷波在 9600 组搜索内无可行解**；S5 可达下界 2.670 ms（目标 1 ms 的 2.67 倍），且这是在 **PM=56.41°** 的舒适裕度下取得的——**缺口与稳定裕度无关**。

### 8.2 Task 5 架构候选的预筛（只评估，未实现）

基于 §3 的模态结论（S5 由 `ln(A_LC/A_tol)/|Re_LC|` 主导），可先做理论排序：

| 方案 | 数学模型 | 所需信号 | 额外成本 | 对 S5 的作用机理 | 50 kHz 可实现性 | 预判 |
|---|---|---|---|---|---|---|
| **A** 优化单环 PI | 已做（§5） | vC | 无 | 只能通过提高环路增益间接增大 `|Re_LC|` | 无瓶颈 | **已排除**（下界 2.67 ms） |
| **B** PI + 鲁棒陷波 | 已做（§5 的 zn/zd/wn 三维） | vC | 无 | 压 `A_LC` 但削弱 `|Re_LC|` | 无瓶颈 | **已排除**（S7/S5 冲突） |
| **C** 电压外环 + 电流内环 | 5 阶（对象 iL,vC + 外环积分 + 内环） | **iL** | 电流采样（分流器/霍尔） | 内环直接给 LC 提供阻尼，`|Re_LC|` 可独立于外环增益提升 | 内环带宽需 ≤ fs/3 ≈ 16.7 kHz；每拍延迟损失 ~9.7° PM（3A.2 T9） | **最值得实现** |
| **D** 电容电流反馈（主动阻尼） | 需 C 电流或 vC 微分 | iC 或 vC 微分 | 高（iC 采样或微分噪声） | 直接注入阻尼项，等效增大 `|Re_LC|` | 微分噪声在 50 kHz 下显著 | 备选，若 C 的带宽不足 |

**量化判据（在实现前先算）**：要让 C6 的 S5 从 6.95 ms 降到 1 ms，需要 `|Re_LC| ≥ ln(A_LC/A_tol)/1 ms`。以 C6×OPT 的 `A_LC = 8.20%` 计：

```
|Re_LC| ≥ ln(8.20) / 1 ms = 2104 rad/s
现状（C6×OPT）= −296.4 rad/s  →  需要快 7.1 倍
```

这个 7.1× 必须由内环支撑。推导（与 3A.2 的控制律一致，`d = Vref/Vin + Kci(iLref − iL)/Vin`）：

```
L·diL/dt = Kci·(iLref − iL) − vC + Vref
        => 内环等价于在电感支路串入一个**虚拟电阻** R_d = Kci  [Ω]
        => LC 谐振对的实部  |Re_LC| ≈ Kci / (2L)        （轻载时的主导项）
        => 内环极点        τ_i = L / Kci ,  f_ci = 1/(2πτ_i)
```

要求 `|Re_LC| = 2104 rad/s`：

| 量 | 取值 |
|---|---|
| `Kci = 2·L·2104` | **0.63 Ω** |
| 对应 `τ_i = L/Kci` | 238 µs |
| 对应 `f_ci` | 670 Hz ≈ 0.8·f_n |
| 3A.2 可实现上限 `Kci ≤ 2π·L·fs/3` | **15.7 Ω** |

**取 `Kci = 1～2 Ω`**（`f_ci = 1.1～2.1 kHz`，比 f_n 略高以便在 840 Hz 处真正提供阻尼），则 `|Re_LC| ≈ 3.3～6.7 krad/s`，是需求的 1.6–3.2 倍。

**结论**：带宽上**有很大余量**（`Kci` 需求 1–2 Ω vs 上限 15.7 Ω，约 8–15 倍），因此方案 C 在 50 kHz 下是可实现的。但**这不等于它会成功**：
- 外环仍需 PM≥50° 且 S5 由 `A_LC` 与 `Re_LC` 共同决定，内环改变 `Re_LC` 的同时也会改变 `A_LC`（可能变大）；
- 每拍延迟损失 ~9.7° PM（3A.2 T9），2 拍即触及 S3 的 6 dB 线；
- 3A.2 已经出现过"纸面可行、时域失败"（双环 dip 分析），必须走完整验证流程。

**注意**：这是纸面推导，**不是结论**。3A.2 已经证明过"纸面好看、时域失败"（双环 dip 分析），所以 C 必须走完整流程：平均模型 → 频域 → 时域 → 离散 → 开关模型。

### 8.3 是否进入架构改造

**建议进入，但只进入 Task 5 的"方案 C 筛选"，且必须先做带宽可行性推导再写代码。**

理由：
- Task 1–4 已把"口径、模态识别、可行域"三件事做实（§8.1），满足用户设定的前置条件。
- 单环族已被**量化排除**（2.67× 缺口，且与 PM 无关），继续调参没有意义。
- 方案 C 的靶点（`|Re_LC|`）正是被证明的瓶颈参数；且纸面带宽需求（`Kci ≈ 0.63`）远低于可实现上限，值得一试。
- **不做**方案 D 的直接实现（微分噪声风险高，且 C 若成功则 D 无必要）。

**仍需守住的边界**：不改 main、不合并 PR、不放宽 S1–S9、不覆盖历史 FAIL、每个 PASS/FAIL 必须有真实执行证据。
