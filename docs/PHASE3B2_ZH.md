# Phase 3B.2：Boost 工程可靠性与 Agent Skills 真实验证

分支 `feat/phase3b1-boost`（基于 PR #2 的 Buck 分支），main 未动。
本报告只写**实际运行得到**的结果；没有运行的实验一律标 SKIP / NOT VERIFIED。

## 0. 三个问题的直接回答

**A. 现有控制架构在什么条件下满足工程要求？**

在**额定与轻载**四个工况（C1 24 V/100 %、C3 28 V/100 %、C4 24 V/50 %、C5 28 V/50 %，
各叠加 +1 A 输出电流阶跃）满足 B1–B12 的全部实测判据。
在 **C2（20 V/100 % + 1 A 阶跃）不满足**，两套限流都不满足，原因不同：

| 设计 | C2 结果 | 直接原因 |
|---|---|---|
| A（Imax 8 A） | vOut 44.36 V（−7.58 %），跌落 −7.77 % | 电流指令需求 9.91 A > 8 A，被限幅 |
| B（Imax 10 A） | vOut 47.88 V（−0.24 %），但恢复 2.25 ms | 稳态够了，恢复时间超 2 ms 上限 |

此外 **B9 在 20 V/150 % 的最坏工况下两套设计都不满足**：该点 RHP 零点降到 1867 Hz，
650 Hz 的穿越频率已经超过 fz/4 = 467 Hz（比值 1.39）。也就是说，这个 650 Hz 的设计
在低压重载角上本来就没有 RHP 余量，与限流无关。

**B. 10 A 方案只是仿真可行，还是已有器件与保护证据？**

**只是仿真可行，而且余量接近零。** 20 V/150 % 稳态下实测 `iLref` 停在 **10.000 A**，
即整个运行点恰好压在限幅上；再叠加任何负载都是失效（C6 加阶跃后 44.17 V）。
器件侧全部为 **NOT VERIFIED**：无电感饱和曲线、无 MOSFET/二极管型号、无热阻、
无电流传感器量程依据。**更关键的是模型里根本没有过流跳闸**——只有一个指令限幅，
真实过流不会被切断（B4c = NOT VERIFIED）。

**C. Agent Skills 是否真正提高了完成能力？可量化证据是什么？**

**不能证明提高，只能说 R1 这条路线本身可用。** 本轮 R1 在固定基准任务上首次执行即通过
（duty 0.5948、fZ 2851.4 Hz、vOut 47.9288 V / −0.148 %、1.84 s）。
R2（官方 MATLAB MCP）与 R3（Skills + MCP）**都是 SKIP**：本会话没有绑定任何
`mcp__matlab*` 工具，`skills/*/SKILL.md` 也没有作为可调用技能暴露。
把"读 SKILL.md 后手写脚本"算作技能触发、或把 `matlab -batch` 算作 MCP，都是作假，
本轮没有这样做。接入条件写在 `docs/MATLAB_MCP_ACCESS_CHECKLIST.md`。

## 2. Task 1：Design A（8 A）与 Design B（10 A）

两套设计**共享全部增益**（Kpe 4.3409、Kie 3545.7、Kci 1.7169、D0 0.511058、
Td 1.5 拍），**只有 Imax 不同**。因此任何差异都可归因于限流。

### 2.1 谁在限制：静差分解

内环是**比例**环：

```
d = D0 + Kci*(iLref − iL_sig)/Vref        (1)
```

稳态时 d 必须等于该工况所需占空比 Dreq，于是

```
iLref_required = iL + droop,   droop = (Dreq − D0)*Vref/Kci        (2)
```

| 工况 | Dreq | iL | dIL | 峰值 | droop | iLref 需求 | A 余量（8 A） |
|---|---|---|---|---|---|---|---|
| C1 | 0.5111 | 4.090 | 1.102 | 4.641 | 0.000 | 4.090 | +3.910 |
| C2 | 0.5948 | 4.935 | 1.063 | 5.467 | 2.340 | 7.275 | +0.725 |
| C3 | 0.4277 | 3.495 | 1.079 | 4.034 | −2.330 | 1.165 | +6.835 |
| C4 | 0.5081 | 2.033 | 1.102 | 2.584 | −0.083 | 1.950 | +6.050 |
| C5 | 0.4252 | 1.740 | 1.078 | 2.279 | −2.401 | −0.661 | +8.661 |
| C6 20 V/150 % | 0.5984 | 7.470 | 1.060 | 8.000 | 2.442 | **9.913** | **−1.913** |

**C2 的阶跃恰好落到 C6 的工作点**（20 V、150 %），所以这一行就是 C2 的判据。

三条结论：

1. **物理上 8 A 够用**：C6 只需要 7.47 A 平均、8.00 A 峰值——8 A 限流本身够。
2. **架构上不够**：比例内环在 Dreq > D0 时带来 2.44 A 静差，把需求推到 9.91 A。
   这才是不合格的原因，不是"电流不够"。
3. 想把静差降下来只有两条路：**加大 Kci**（吃相位裕度）或**给内环加积分**（未实现）。
   实测减小 Kci 会更差（静差反比于 Kci）。

### 2.2 实测矩阵（需求集 C1–C5，各 +1 A 输出阶跃，3 个种子）

| 设计 | 通过 | 失败工况 |
|---|---|---|
| A（8 A） | **12 / 15** | C2 ×3（vOut 44.36 V，−7.58 %，跌落 −7.77 %） |
| B（10 A） | **12 / 15** | C2 ×3（vOut 47.88 V，−0.24 %，但恢复 **2.25 ms** > 2 ms） |

**10 A 并没有把 C2 救回来，只是把失败项从"调不下来"换成了"回得太慢"。**
这是本轮最容易被误读的一条：3B.1 报的"Imax=10 A → 5/5"用的是另一套更宽松的工况
（最大只到 20 V/100 % 再叠加 +1 A），而 C2 把负载推到 150 % 后，恢复时间就越线了。

### 2.3 压力点（150 % 额定，纯稳态，150 ms）

| 工况 | A（8 A） | B（10 A） |
|---|---|---|
| C6 20 V/150 % | **44.37 V（−7.6 %）** | 47.89 V（−0.2 %），`iLref` 顶在 10.000 A |
| C7 24 V/150 % | 47.92 V（−0.2 %） | 47.92 V（−0.2 %） |

B 在 C6 是"刚好站住"：指令停在限幅上，没有任何动态余量。
解析式给 9.913 A、实测需要 ~10.0 A，差 0.09 A 来自纹波不对称（谷值比 `dIL/2` 更低）
与传感器 +2 % 增益 / +0.05 A 偏置。

### 2.4 器件与保护

| 项 | 状态 | 原因 |
|---|---|---|
| 电感峰值/饱和 | NOT VERIFIED | 无型号、无 Isat 曲线，C6 峰值 8.00 A |
| MOSFET / 二极管额定 | NOT VERIFIED | `RonSW/RonD/Vf` 均为占位值 |
| 电流传感器量程 | NOT VERIFIED | 12 A 量程是假设 |
| 热与温升 | NOT VERIFIED | 无损耗-热模型、无 Rth |

## 4. Task 3：Simulink 工程

### 4.1 两个模型

| 文件 | 大小 | 内容 |
|---|---|---|
| `matlab/boost/models/boost_avg.slx` | 67 523 B | 两状态平均模型 + 双环离散控制 + 真实负载阶跃 |
| `matlab/boost/models/boost_sw.slx` | 74 979 B | 50 kHz PWM、开关、二极管单向导通、DCM、ESR/DCR/导通损耗、ZOH 离散控制 |

由 `build_boost_avg.m` / `build_boost_switching.m` 程序化生成，全部使用库模块与常量，
**不使用任何基础工作区变量**（`Simulink.findVars` 返回 0），因此不依赖预置 MAT 或路径。

**DCM 不是"检测"出来的，是被积分器强制出来的**：`iL` 用 `Integrator Limited`，下限 0。
OFF 期间导数想把电流拉负时，状态停在 0，正好就是二极管的行为。

### 4.2 与 MATLAB 引擎对照

| 平均模型占空比 | 0.511058 | 0.511058 | <1e-12 |
| 平均模型阶跃 dip | −1.1205 % | −1.0849 % | 0.036 pp |
| 平均模型 S5 | 0.5321 ms | 0.4990 ms | 0.033 ms |
| 开关模型稳态 vOut | 47.9794 | 47.9486 | +0.064 % |
| 开关模型 iL | 4.0872 | 4.0763 | +0.011 A |
| 开关模型 iL 纹波 | 1.1172 A | 1.0887 A | +2.6 % |

**0.064 % 的稳态偏移是采样沿定义，不是误差**：开关模型在周期边界采样，而这一刻正是
ESR 阶跃点（二极管电流从 iL 跳到 0）。采在沿前还是沿后差 `ESR·iL/(1+ESR/R) ≈ 100 mV`。
这里采在沿后，MATLAB 引擎采在沿前。两个数都真实，差的是约定。

即 200 子步已经收敛，验收结论不会被步长左右。

## 8. 未解决问题

| # | 问题 | 影响 | 为什么没解决 |
|---|---|---|---|
| U1 | 内环比例静差 2.44 A（20 V） | 直接决定 8 A 是否够用 | 需要给内环加积分或提高 Kci；两者都会改变已冻结的基线，应作为独立设计迭代 |

| U5 | 开关模型 0.064 % 稳态偏移 | 与引擎对比时分不清是误差还是约定 | 需要定义"在哪个沿采样"，并让两侧一致 |

## 9. 下一阶段建议

1. 先做 **U1/U2 的设计迭代**（内环积分 + 带宽调度），这两项决定 Boost 能否覆盖 20 V 角；
   不建议在它们解决前进入器件选型。
2. **U3 保护策略**必须在硬件之前定稿，否则 10 A 方案只是纸面数字。
3. 三相逆变器（Phase 3C）的判据要**重新测量后再定**：本轮的 B9 已经证明，
   把一个"看起来合理"的经验式（fc ≤ fz/4）套到不同工况会给出相反结论。
4. Agent 侧：拿到 MATLAB MCP 绑定后，先跑 `MATLAB_MCP_ACCESS_CHECKLIST.md` 的六步，
   再谈"Skills 提高效率"。
