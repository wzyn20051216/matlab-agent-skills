## 2. Task 1：修复 D 级验收语义

### 2.1 3A.5 的 S1 错在哪

3A.5 的 D 级 S1 实现是：

```matlab
okS1 = isfinite(m.settleMs) && abs(ssErr) <= STD.sserr_max;
```

这只说明「在 60 ms 窗口内输出进了带并且稳态误差小」。两个反例：

- **慢增长振荡**：时间常数 20 ms 的弱不稳定，在 60 ms 内只涨 3 倍，看起来「收敛」；
- **极限环**：波形完全重复、有界、稳态误差为 0，但根本不是稳定平衡点。

3A.5 自己就撞上过第二个反例（2 拍延迟时 `S5 = NaN`、~4 kHz 振荡），只是因为 `settleMs = NaN`
才被 `isfinite` 拦住——**这是运气，不是判据**。

### 2.2 换成周期映射的 Floquet 乘子

开关变换器是**周期系统**，不是时不变系统，正确的对象不是「线性模型的极点」而是
**周期轨道的 Floquet 乘子**。定义闭环一个周期的映射

```
x_{k+1} = P(x_k),   x_k = 第 k 个开关周期起点的状态
```

则周期轨道 `x*` **局部渐近稳定 ⟺ 所有 |λ(DP(x*))| < 1**。这是关于采样动力学的精确命题，
不需要时间窗口、不需要平均模型。

实现（新增）：

| 文件 | 作用 |
|---|---|
| `sw_period_map.m` | 闭环**一个周期**的映射。状态 `[iL; vC; xI; dHist; yS; m]`，含占空比流水线（计算延迟）、传感器滤波与传输延迟 |
| `sw_floquet.m` | 迭代到周期稳态 → 数值 Jacobian → 特征值；并用「50 mV 扰动衰减率」交叉验证线性化是否可信 |
| `s1_verdict.m` | **S1 的唯一判定实现**（`converged && maxAbs<1`），验收脚本与回归测试共用 |

三个实现细节值得记下来：

1. **占空比在一个周期内是常量**，锯齿载波从 0 起，所以导通时间恒为 `d·Ts` 且在周期**起点**——
   周期被解析地分成两段，映射对 `d` 光滑，Jacobian 才有意义（不需要事件检测）。
2. **复极点**：`A` 的特征值是一对复根，用特征分解求 `expm(A·t)` 会带回纯舍入噪声的虚部，
   必须 `real()` 取实——否则 `repmat/floor` 会报「复数复制因子」（本轮踩到）。
3. **没有周期-1 轨道时，乘子无定义**。2 拍延迟就是这种情况：迭代不收敛，此时报
   「`max|λ| = 0.99，不稳定」是**错误推理**——它在一个不是轨道的点上求值。正确表述是
   「**不存在周期-1 轨道**」。这一条已写进代码注释与输出。

## 3. Task 2：D+ 联合非理想模型

### 3.1 为什么要新建引擎

Simulink 开关模型每次运行约 45 s（含建模开销），做 5 个噪声种子 × 7 工况 × 4 个电感候选
就要 2 小时以上。所以新增 `sw_dual_sim.m`：**逐周期、开关时刻精确、含完整传感器链**的
MATLAB 仿真器。

- 传播方式：每个开关状态内 `dz/dt = A z + b` 是 2 阶 LTI，用**矩阵指数精确传播**；
  开关时刻用特征分解在任意时长上精确求值（不做子步量化）；
- 单次运行 **2.0 s**（比 Simulink 快约 20 倍）；
- **它只用于通道扫描，绝不替代参考模型**。

- 每个格子是 **D+ 引擎 × 3 个噪声种子**的最坏结果（共 84 次运行）。
- 开关纹波 = 无传感器噪声时的输出纹波（C1 标称）；含噪抖动 = 有噪声时的最坏值。
- DCR/储能是**一阶缩放估计**（`R_dc ∝ √L`、储能 ∝ `L·I²`），不是磁设计输出。

### 4.3 读法：没有一个候选全面更好

（图 `a6_summary.png` 为本地生成产物；证据目录 `artifacts/` 不随仓库分发）

> 左上：14 个轨道距单位圆的距离，柱高为 0 即失稳；左下：加大 L 的代价；右上/右下：L 的四条
> 曲线方向不一致。图由 `verify/buck_a6_figure.m` 直接读两个 JSON 绘制，**不重跑仿真**。


这四条曲线**方向不一致**，这正是任务书警告的那件事：

| 指标 | 150 → 470 µH 的变化 | 单调？ |
|---|---|---|
| 纹波率 | 125.6% → 39.4% | ✅ 单调变好 |
| 稳态误差 S4 | 0.0977% → 0.0343% | ✅ 单调变好（**余量从 2.3% 恢复到 66%**） |
| iL 峰值 | 12.04 → 9.44 A | ✅ 单调变好（不再超 Imax） |
| 开关纹波 | 17.5 → 5.6 mV | ✅ 单调变好 |
| 输出抖动（噪声） | 68.0 → 30.8 mV | ✅ 单调变好 |
| **电压跌落 S7** | **−4.93% → −7.83%** | ❌ **单调变差** |
| **S5 调节时间** | 0.6745 → 0.5746 → 0.7175 → 0.8160 | ❌ **非单调，220 µH 最优** |

**为什么跌落会变差**：跌落的恢复能力由可用电流斜率决定

```
diL/dt|max = (Vin·Dmax − Vout)/L = (40.8 − 12)/L
L=150 µH : 192 kA/s      L=470 µH : 61 kA/s   （降到 32%）
```

补足 2 A 的电流缺额分别需要 10 µs 和 33 µs，而 S5 的预算只有 1000 µs 中的一小段。
**加大电感必然牺牲负载瞬态，这不是控制能补偿的**——外环再快也不能让电感电流爬得更快。

**为什么 S5 非单调**：S5 由「跌落深度」和「回带后的振荡」共同决定。220 µH 处两者恰好平衡
（跌落 −5.62%、振荡更小）；到 330/470 µH 时跌落主导，S5 反而变长。

**为什么 S4 改善这么多**：ssErr 的正比于纹波谷值与平均值的差（`ESR·ΔI/2` 加上采样偏置）。
纹波从 1.25 App 降到 0.39 App，这个系统性偏置从 0.098% 降到 0.034%。**S4 的瓶颈是硬件，
不是控制**——这一点在 3A.5 已经推断出来，本轮用四个电感值证实了。

### 4.4 关于 DCR 与体积的代价

| L | 匝数比 | DCR | 铜损（直流，同电流） | 储能 | 相对体积（估） |
|---|---|---|---|---|---|
| 150 µH | 1.00 | 1.00× | 1.00× | 1.00× | 1.00× |
| 220 µH | 1.21 | 1.21× | 1.21× | 1.47× | ~1.5× |
| 330 µH | 1.48 | 1.48× | 1.48× | 2.20× | ~2.2× |
| 470 µH | 1.77 | 1.77× | 1.77× | 3.13× | ~3.1× |

**这些都是量级估计，不是磁设计结果**。真实设计中 DCR 还受绕组窗口、线径、气隙、饱和电流影响，
而「储能 ∝ L·I²」在同一个磁芯上意味着**体积约按 L 增长**。若要严格比较，需要选型 + 损耗计算，
本轮**没有做**（未做项，见 §6）。

**一个容易被忽略的代价**：DCR 增大会降低效率，而效率下降又会让同样的输出功率需要更大的
输入电流，进而略微增大纹波——二阶效应，本轮未建模。

## 5. 冻结建议

### 5.1 冻结判定的四个问题

| 问题 | 答案 | 依据 |
|---|---|---|
| 稳定性有独立证据吗？ | **有** | Floquet 14/14 `max\|λ\| < 1`，最坏 0.969，与平均模型差 ≤2.8% |
| 非理想叠加后还达标吗？ | **是** | D+ 35 次运行 7/7；S5 最坏 0.6745 ms |
| 余量够吗？ | **不够均匀** | S4 余量 2.3%、S8 零余量、iL 峰值超 Imax 0.3% |
| 硬件验证了吗？ | **没有** | E 级 SKIP |

### 5.2 冻结建议：分两级

**A. 可以冻结的（现在就可以）：「v1 仿真基线」**

- 控制器参数 `Kci=6, Kp_e=1.8, Ki_e=4000, ff=1, Tss=5ms` 冻结，不再调参；
- 全部验收数据（A/B/C/D/D+）冻结为基线，后续改动必须与它对比；
- 已量化的假设清单（10 条，3A.5 §7.3 + 本轮 §3）作为**设计输入条件**冻结。

**B. 不能冻结的：「可发布的旗舰 Demo」**

理由不是「数据不好看」，而是三条硬约束：

1. **没有硬件**。一个电源控制器的最终证据只能是实测波形。目前 D/D+ 的结论全部是仿真，
   而仿真里连开关损耗、反向恢复、结电容都没有（基础模块模型）。
2. **S4 只剩 2.3% 余量**，且它由硬件（纹波率）决定，不是控制能修的。一旦实测纹波比模型大
   5%，S4 立刻失守。
3. **S8 零余量**：duty 下界在恢复段**恰好**等于 0.050。实测若跑到 0.049 就是 FAIL。

### 5.3 如果一定要在硬件前做一件事

**把 L 从 150 µH 换成 220 µH。** 这是四个候选里唯一同时改善 S4、S5、iL 峰值和纹波的：

| 指标 | 150 µH | 220 µH | 变化 |
|---|---|---|---|
| S4 稳态误差 | 0.0977% | 0.0679% | 余量 2.3% → **32%** |
| S5 最坏 | 0.6745 ms | 0.5746 ms | 余量 33% → **43%** |
| iL 峰值 | 12.04 A | 10.61 A | 不再超 Imax |
| 纹波率（最坏） | 125.6% | 84.4% | 接近可接受 |
| S7 跌落 | −4.93% | −5.62% | 余量 59% → 53%（仍充裕） |
| DCR / 储能 | 1.00× | 1.21× / 1.47× | 代价 |

**不推荐 330/470 µH**：纹波继续降，但 S5 反而变差（0.72 / 0.82 ms），而 DCR 与体积代价
已经到 1.5–3 倍。收益与代价不匹配。

**注意**：这是**建议**，不是本轮已实施的变更。150 µH 的基线及其全部结果完整保留。

### 5.4 发布前还必须补的三件事（按优先级）

| 优先级 | 事项 | 为什么 |
|---|---|---|
| 1 | 硬件原型 + 实测（E 级） | 唯一能给出最终证据的事 |
| 2 | 若 S4 实测不达标，换 220 µH 重测 | 唯一能救 S4 的手段（本轮已验证方向） |
| 3 | 实测电流纹波与 duty 下限 | S8 零余量，必须实测确认 |

### 5.5 本轮的边界（没做的事）

1. **无硬件**（E 级 SKIP），全部结论止于模型。
2. **无器件级模型**：基础模块开关模型不含反向恢复、结电容、开关损耗、导通损耗的温度特性。
3. **无 DCM 模型**：C4 的电流谷值 0.375 A，距 DCM 仅 0.375 A。L=470 µH 时边界降到 0.191 A，
   裕度 5.2×，但本轮**没有验证 DCM 行为**（模型允许二极管反向导通）。
4. **无磁设计**：DCR/体积是一阶缩放估计。
5. **S2/S3 在开关级仍未独立验证**，只有设计值 + 两个标量裕度替代。
6. **未做增益调度**：C7（L+30%）靠固定参数通过，L−30% 未测（会收紧采样约束）。
7. **Floquet 只覆盖边界采样**：`sampPhase ≠ 0` 的配置需要把上一周期的积分速率也放进状态，
   本轮未实现，映射会**显式报错**而不是静默错算。

## 8. 追记（Phase 3A.6 续：Task 4–7 之后）

本节由 Task 4–7 的执行追加，**不修改上文任何数字**，只追加四条例更正与一条新结论。
完整报告：`docs/PHASE3A6B_TASKS4_7_ZH.md`。

### 8.1 "7/7" 需要加口径

上文 §6 的 7/7 是**S1–S9 原文判据**下的结论，这一点仍然成立（本轮机重跑了 140 次，
基线 35/35 有周期-1 轨道、33/35 通过全部实测判据）。但同一张表里并列的"iL 峰值 12.04 A"
在**严格 12 A 器件限值**下是不合格的：

| 口径 | 结果 |
|---|---|
| S1–S9（不含峰值电流） | 7/7 |
| S1–S9 + 严格 12 A | **6/7**（C6 超 0.041 A） |

Task 2 的 `okIpk = iLpk <= 1.10*Imax` 是一处**标准放宽**，本轮已改回严格口径。
根因：`Imax=12 A` 限的是**电流命令**（周期平均），瞬时峰值必然高出 ΔiL/2。

### 8.2 S6 判为 UNDETERMINED

上文 §6 表里 S6 的"66% 余量"没有意义：仿真的初值就在 12 V 工作点，参考从 0 V 斜坡上升，
`max(vOut)/Vref−1 ≈ 0.8~1.5%` 基本就是初值本身。且启动段电感电流为 **−0.87~−1.83 A**，
二极管不可能反向导通——真实电路此时进 DCM，模型没有 DCM 状态。**S6 实际未被测过。**

### 8.3 S4 与 S8 的贴线是两件不同的事

- **S4 的 0.0977%** = 外环在周期边界采到输出纹波**谷值**并把它调到 12.0000 V，
  于是均值高出 (均值−谷值)=8.1~11.4 mV。七工况的 `min(vOut)` 全部精确等于 12.0000 V，
  与该差值一一对应；与 ADC 分辨率、噪声、窗口长度都无关。**机理清楚、可补偿。**
- **S8 的 0.050** 只出现在负载阶跃恢复的 1~2 个开关周期（占后段样本 0.1~0.3%），
  工作点占空比是 0.229~0.294。**不是工作点饱和。**

### 8.4 电感裕度只有 −3.3%（本轮最重要的新结论）

`Kci ≤ L/Ts = 120 µH` 只是**必要条件**。实测：150 µH 稳定（max|λ|=0.9653），
145 µH 通过（0.9812），**140 µH 临界（0.9978 且 1500 周期不收敛），135 µH 失稳（1.0041）**。
即稳定下限约 **145 µH（−3.3%）**，成品电感 ±10%/±20% 都会让部分样机失稳。
`Kci` 的实测裕度只有 **×1.016**。

因此 **L=220 µH 不只是"仿真候选"，而是让 ±20% 电感公差变得可用的最小改动**
（220 µH 配置在 Task 6 里 21/21 通过，峰值电流降到 10.60 A）。

### 8.5 结论是否需要改写

- "可以冻结为**仿真**验证完成的 v1 候选" —— **成立**，且现在有更强的跨版本一致性证据
  （重构前后 ΔS5=0、Δdip=4e-14）。
- "不能冻结为可发布的旗舰 Demo" —— **成立**，并且理由更硬了：不是"缺硬件"一条，
  还有"电感裕度 −3.3%"与"峰值电流越限"。
