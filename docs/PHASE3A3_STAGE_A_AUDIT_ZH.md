## 0. 一句话结论

**3A.1/3A.2 两轮对 S5 瓶颈的归因都是错的。**

报告的"−82.2 rad/s 慢极点（τ=12.17 ms）导致 S5 需要 4.4–8.5 ms"这一因果链不成立。用**实测波形的精确模态分解**（残差 RMS = 0.00000 V，预测 S5 与实测吻合到 0.001 ms）证明：

## 3. Q1：−82.2 rad/s 极点属于谁？

### 3.1 身份

它是 **OPT 控制器**（陷波器 + PI，Kp=0.04, Ki=5）在 **C1/C2/C3/C4/C5/C6** 六个工况下的**最右闭环极点**，是一个**实数极点**，来源是**电压环 PI 的积分器**。

闭式近似（报告用的就是这个）：

```
p_dom ≈ −Ki·Vin / (1 + Kp·Vin)
```

| 控制器 | Kp | Ki | 精确主导极点 | 闭式 −Ki·Vin/(1+Kp·Vin) | 偏差 |
|---|---|---|---|---|---|
| BASE | 0 | 7.9029 | **−381.144** | −379.339 | 0.48 % |
| OPT | 0.0400 | 5.0000 | **−82.651** | −82.192 | 0.56 % |

闭式与精确值吻合到 0.6 %，说明**报告"−82.2 rad/s"这个数字本身是对的**（它是闭式值），只是没标注是近似。

### 3.2 工况依赖

极点随 Vin 线性缩放、几乎与 R 无关，与闭式一致：

| 工况 | Vin | R | OPT 最右极点 |
|---|---|---|---|
| C1 | 48 | 6 | −82.651 |
| C2 | 42 | 6 | −78.814 |
| C3 | 54 | 6 | −85.901 |
| C4 | 48 | 12 | −82.622 |
| C5 | 48 | 3 | −82.710 |
| C6 | 54 | 3 | −85.960 |
| C7 | 48 | 6 (L+30%) | **+82.711（不稳）** |

### 3.3 关键：`maxRe` ≠ 主导极点

C1 完整极点谱（模态幅值 = `|residue/p|`，相对 DC 增益）：

**BASE（3 个极点）**

| 极点 | 模态幅值 | 占比 |
|---|---|---|
| −188.216 ± 5488.5j（LC 谐振对） | 3.47 % ×2 | 3.25 % |
| **−381.144（实）** | **99.99 %** | **93.4 %** |

**OPT（5 个极点）**

| 极点 | 模态幅值 | 占比 |
|---|---|---|
| **−82.651（实，积分器）** | **34.07 %** | 32.7 % |

| −2932.99 ± 9102.0j（陷波器极点对） | 33.23 % ×2 | 63.7 % |

**所以对 BASE，`maxRe=−188.22` 不是主导极点**——它是一对模态幅值只有 3.47 % 的 LC 谐振极点；真正主导参考阶跃的是 `−381.144`。报告 §1.1 表把 `maxRe` 当"主导极点"表述，会误导。

## 4. Q2 + Q3：该极点的真实贡献，以及 4.4–8.5 ms 是否与它一致？

### 4.1 为什么不能用 T(s) 的留数解释负载阶跃

**负载阶跃是对象参数变化（R 从 6 Ω 变 3 Ω），不是加性扰动。** `T(s)`（参考→输出）的留数描述的是**参考阶跃**，不能直接搬到 S5。

这一点正是 3A.2 出错的地方：它用 `T(s)` 的留数（34 %）说明"慢极点主导"，但 S5 考核的是**负载阶跃**。

数值对照（C1×OPT）：

| 激励 | 慢极点（−82.65）的模态幅值 | 该激励下的调节时间 |
|---|---|---|
| 参考阶跃 | **34.07 %**（留数分析） | 34.27 ms（`stepinfo`，1 % 带） |
| **负载阶跃（S5 的口径）** | **0.17 %** | **7.35 ms**（实测） |

两者差 200 倍。**把参考阶跃的留数用来解释负载阶跃的 S5，是本次归因错误的根源。**

### 4.2 正确的做法：阶跃后模态的精确分解

负载阶跃后系统仍是线性的，响应必然是**阶跃后闭环极点**的线性组合（系数由切换时刻 iL、vC 的连续性唯一确定）。以阶跃后（R=3 Ω）的闭环极点作基函数，对实测波形做最小二乘：

**C1 × BASE**（残差 RMS = **0.00000 V**，即精确分解）

| 模态 | Re | 频率 | 幅值 |
|---|---|---|---|
| LC 谐振对 | −565.1 | 865 Hz | **14.00 %** |
| 实极点 | −384.9 | — | 0.986 % |

**C1 × OPT**（残差 RMS = **0.00000 V**）

| 模态 | Re | 频率 | 幅值 |
|---|---|---|---|
| 陷波器极点对 | −3250.8 | 1471 Hz | 6.98 % |
| **LC 谐振对** | **−217.8** | **838 Hz** | **5.18 %** |
| 实极点（积分器） | −82.7 | — | **−0.17 %** |

**14/14 全部落在 800–875 Hz 的 LC 谐振环上，没有一个是积分器极点。**

### 4.4 数学解释（这就是"为什么是 4.4–8.5 ms"）

单一模态近似下，进入并常驻 δ 误差带的时间：

```
S5 ≈ ln(A_mode / δ) / |Re_mode|          A_mode = 该模态的初始幅值
```

C1×OPT：`ln(5.18 %/1 %) / 217.8 = 1.6446 / 217.8 = 7.55 ms`，实测 7.35 ms（差值由 1471 Hz 陷波模态的快速衰减略微抵消）。
C1×BASE：`ln(14.00 %/1 %) / 565.1 = 2.639 / 565.1 = 4.67 ms`，实测 4.46 ms（同上）。

**为什么 BASE 的 S5（4.46 ms）反而优于 OPT（7.35 ms）？** 尽管 OPT 的 dip 更小（−7.8 % vs −11.2 %）：

| | LC 谐振 Re | τ = 1/|Re| | 谐振幅值 | S5 |
|---|---|---|---|---|
| BASE | −565.1 | 1.77 ms | 14.00 % | **4.46 ms** |
| OPT | −217.8 | **4.59 ms** | 5.18 % | **7.35 ms** |

**OPT 把谐振幅值压到 1/2.7，却把谐振阻尼削弱到 1/2.6。** 因为 S5 是对数依赖幅值、线性依赖时间常数，所以"幅值减半、τ 加倍"的净效果是**变差**。这是 3A.2 完全没有捕捉到的机制——它只看了 dip（幅值），没看 τ。

### 4.5 交叉核验（三路独立）

| 证据链 | 结果 |
|---|---|
| ① 模态分解重构 S5 | 14/14 偏差 ≤ 0.04 %（§4.3） |
| ② 尾部指数拟合衰减率 | C1×OPT：拟合 83.81 rad/s vs 极点 82.65 → 偏差 **1.40 %**（但注意：拟合窗口 15–55 ms 抓到的是**最慢的可见分量**，不是主导 S5 的分量） |
| ③ 官方工具 `pole` / `damp` | `maxRe` 与 `damp` 的 `max(Re)` **完全一致**（C1 两控制器均 `ok=1`），交叉验证极点计算无误 |

**② 的提示很重要**：3A.2 若只做尾部拟合，会得出"衰减率 ≈ 82 rad/s"的错误结论，因为 15–55 ms 窗口里 LC 谐振（τ=4.59 ms）已经衰减到 1 % 以下，剩下的是积分器模态的高频噪声尾巴。**必须做全模态分解才能定性。**

## 5. Q4：S5 的实现口径与仿真窗口

### 5.1 口径核对

用户要求的定义：*从负载阶跃时刻起，输出电压进入 ±1 % 目标误差带，并从此**持续保持**在误差带内的时间。*

| 主导极点识别 | `maxRe` vs **模态幅值** | **不一致**（BASE：−188.22 vs −381.14）；这正是 D-A6 |
| 闭式极点 | `−Ki·Vin/(1+Kp·Vin)` vs `pole()` | 偏差 0.48 % / 0.56 %（A7） |
| 负载阶跃模态 | 最小二乘模态分解，残差 RMS | **0.00000 V**（精确） |
| S5 重构 | 模态和前向仿真 vs 实测 | 14/14 偏差 ≤ 0.04 % |
| PM/GM | `local_margins` vs `allmargin` | PM 一致（57.28/59.27 属不同交越口径，见下） |
| 窗口 | 末段在带时长 vs 时间常数 | ≥ 11 τ，充分 |

**关于 `allmargin` 的两点口径差异（不是新缺陷，需在阶段 B 沿用既有约定）**：

1. `allmargin(Loop)` 对 BASE×C1 给出 **GM=1.997 dB**，而 `local_margins` 的全交越最坏值给出 **6.01 dB**。按 3A.2 已固化的约定，**GM 以全交越最坏值为准**（`allmargin` 只取首个相位穿越）。
2. `allmargin` 对 OPT×C1 给出 PM=**59.27°**，而 `local_margins` 给 **57.28°**；两者是不同交越点（3 个 0 dB 交越中的最坏值 vs 首个）。**沿用 `local_margins`。**

## 7. S2 / S5 的冲突到底证明到什么程度？

用户要求严格区分「扫描未找到」与「数学上证明无解」。**当前证据只能支持前者。**

### 7.1 补充扫描（C1 额定，Kp=0.04 + 定稿陷波器固定）

| Ki | Keff = Ki·Vin/(1+Kp·Vin) | PM | GM | τ = 1/Keff |
|---|---|---|---|---|
| **5.0**（定稿） | 82.2 | 57.28° | Inf | 12.17 ms |
| 15.0 | 246.6 | 55.48° | Inf | 4.06 ms |
| 30.0（OPT30） | 493.2 | 52.60° | Inf | 2.03 ms |
| 45.0 | 739.7 | **48.70°** | Inf | 1.35 ms |
| **56.4**（S5=1 ms 所需） | 927.1 | **45.83°** | Inf | 1.08 ms |
| 70.0 | 1150.7 | 42.53° | Inf | 0.87 ms |
| 100.0 | 1643.8 | 35.92° | Inf | 0.61 ms |
| 250.0 | 4109.6 | 15.16° | 24.43 dB | 0.24 ms |

**在 C1 单工况**：S2 边界（PM=50°）落在 Ki ≈ 40；要把 S5 压到 1 ms 需 Ki ≈ 56，此时 PM=45.83° < 50°。**冲突在 C1 就已成立，但差距只有约 27 %（1.27 ms vs 1.0 ms）。**

### 7.2 为什么这**还不能**叫"证明无解"

1. **C6 才是约束最紧的工况**：Ki=5 时 C6×OPT 的 PM 已经只有 **48.05°**（低于 50°）。也就是说，在 7 工况口径下，现有家族的 Ki 上限甚至低于 5，S5 的差距远大于 C1 的 27 %。
2. `Kp` 与陷波器参数（`zn`、`zd`、`wn`）**都是自由变量**，上面的扫描只沿 Ki 一维走。
3. **真正的物理杠杆在 §4 才被定位**：S5 由 `ln(A_LC)/|Re_LC|` 决定，而 `A_LC` 与 `Re_LC` 可以**独立于 PM 调节**——主动阻尼（电流内环 / 状态反馈 / 虚拟电阻）正是为此存在。

因此，3A.2 的"S2 与 S5 硬冲突"应降级为：**「在 (Kp=0.04, Ki, 定稿陷波器) 这一维家族内、7 工况口径下，未找到可行解」，且差距在 C1 处仅 27 %。** 数学上无解**未被证明**。

### 7.3 修正后的机理（这才是阶段 B 的正确起点）

```
S5 ≈ ln(A_LC / 1%) / |Re_LC|
        ↑                ↑
   谐振激励幅值      谐振阻尼
   （dip 越小越好）   （τ 越小越好）
```

- **提高 Ki**：同时增大 `|Re_LC|`（好）和降低 PM（坏）→ 这就是 S2/S5 冲突的**真实机理**（不是"积分器变快"）。
- **加深/加宽陷波**：压 `A_LC`（好），但削弱 `|Re_LC|`（坏）→ 这是 OPT 反而比 BASE 慢的原因。
- **解耦这两者的唯一办法**：引入**独立于电压环增益的谐振阻尼通道**。这就是阶段 C 应当验证的对象。

## 9. 结论与是否进入阶段 B/C

### 9.1 阶段 A 交付的结论

1. **−82.2 rad/s 极点的身份已确定**：OPT 控制器、C1–C6 工况、实数极点、来源是 PI 积分器，闭式 `−Ki·Vin/(1+Kp·Vin)` 吻合 0.56 %。
2. **它对 S5 没有实质贡献**：负载阶跃响应中的模态幅值 **0.17 %**（频带 1 %），14 个收敛案例中**没有一个是它主导**。
3. **4.4–8.5 ms 与报告的慢极点"表面接近、实则无关"**：7.35 ms 由 `ln(5.18)/217.8` 决定（LC 谐振），12.1 ms 是积分器时间常数，两者数量级接近纯属巧合。**这就是 D-A1 的定位。**
4. **真实瓶颈 = 闭环 LC 谐振环（800–875 Hz）的阻尼与激励幅值**，`S5 ≈ ln(A_LC/1%)/|Re_LC|`，14/14 验证到 0.04 %。
5. **OPT 的 S5 比 BASE 更差的原因**：谐振幅值降到 1/2.7，但阻尼削弱到 1/2.6；对数-线性不对称使净效果为负。
6. **S5 口径方向正确**，仅 1 µs（1 采样点）低估，不影响判定；**窗口充分**（≥11 τ）；**未发现把未判定标成 PASS**。
7. **"S2/S5 硬冲突"未被证明**，只证明"在 (Kp, Ki, 定稿陷波) 一维家族内未找到解，C1 处差距 27 %"。

### 9.2 是否进入阶段 B/C

**建议进入，且优先级应调整：C 的靶点比 B 更明确。**

理由：

- **阶段 B（S2/S5 可行性边界）** 值得做，但必须把搜索维度从"Ki 一维"扩到 `(Kp, Ki, zn, zd)` 四维，并明确报告"可行域为空"是**在哪个给定家族内**为空。它是"证明无解"的必要步骤。
- **阶段 C（电流内环）现在有了明确的物理依据**，不再是盲目试错：**它直击 `|Re_LC|`（谐振阻尼）这一个被证明的瓶颈参数**，而不依赖提高电压环增益。3A.2 否定双环的理由（`ζ ∝ 1/Ki_e`）针对的是 dip，与 S5 无关（D-A3），**不构成对阶段 C 的反证**。
- 但仍需按用户要求先做**带宽需求推导**：`|Re_LC| ≥ ln(A_LC/1%)/1ms`。以 C6×OPT（最紧，A_LC=8.20 %）计，需要 `|Re_LC| ≥ ln(8.2)/0.001 ≈ 2104 rad/s`，即比现状 −296.4 rad/s 快 **7.1 倍**。这个数字必须由内环带宽能否在 50 kHz 开关频率下实现来检验（含采样与计算延迟，每拍代价约 9.7° PM / 9.3 dB GM，延迟 2 拍即触及 S3 线）。
