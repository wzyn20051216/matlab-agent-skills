### 0.1 一句话

**双环（电压外环 PI → 电感电流指令 → 电流内环 → 占空比）在本硬件上是有效的**：

## 2. Task 1：双环的精确数学模型

### 2.1 控制律与量纲

```
e      = Vref − vC                                   [V]
iLref  = Kp_e·e + Ki_e·xe (+ ff·iLoad)                [A]
dxe/dt = e                                           [V]
d_raw  = Vref/Vin + Kci·(iLref − iL)/Vin             [1]
d      = sat(d_raw, Dmin, Dmax)
```

| 增益 | 单位 | 物理含义 |
|---|---|---|
| `Kci` | V/A = **Ω** | 电流环的**虚拟串联电阻**。由 `L·diL/dt = Kci(iLref−iL) − (vC−Vref)` 得出 |
| `Kp_e` | A/V | 外环比例：每 1 V 电压误差给出多少安培电流指令 |
| `Ki_e` | A/(V·s) | 外环积分 |
| `xe` | A/A/(V·s) = V·s | 外环积分状态 |
| `d` | 无量纲 | 占空比 |

**前馈常数必须是 `Vref/Vin`，不能是 `vC/Vin`。**
写成 `vC/Vin` 时 `Vin·d = vC` 恒成立，电感电压恒为 0，**任何 vC 都是平衡点**，
外环无法镇定（3A.2 已定位，本轮沿用并再次在 §2.3 的稳态检查中验证）。

### 2.2 精确闭环特征方程（本轮的关键推导）

状态 `x = [iL; vC; xe]`：

```
A = [ −Kci/L , (−Kci·Kp_e + ff·Kci/R)/L ,  Kci·Ki_e/L ;
       1/C   ,      −1/(R·C)            ,      0      ;
       0     ,          −1               ,      0      ]
```

**ff = 0 时**（纯双环）：

```
det(sI − A) = s³ + (Kci/L + 1/(RC))·s²
                 + ( Kci/(L·R·C) + (1 + Kci·Kp_e)/(L·C) )·s
                 + Kci·Ki_e/(L·C)
```

**ff = 1 时**（负载电流前馈）：

```
det(sI − A) = s³ + (Kci/L + 1/(RC))·s²
                 + ( Kci·Kp_e/(L·C) )·s
                 + Kci·Ki_e/(L·C)
```

注意 ff=1 时 s 项里的 `Kci/(L·R·C)` 与 `s²` 项里的 `1/(RC)` 来源不同，
**不能靠"把 1/R 项相消"来理解**；正确的物理解释是
**内环被控量从 iL 换成了 iC**（见 §2.4）。

数值校验（`Kci=2, Kp_e=0.5, Ki_e=500`）：

```
analytic [s^3 s^2 s 1] = [1  14090.909  70707071  3.030303e+10]
pole()   [s^3 s^2 s 1] = [1  14090.909  70707071  3.030303e+10]
max relative error     = 4.215e-16
poles                  = [-471.369, -6809.77 ± j4232.53]
Routh–Hurwitz c2*c1>c0 = 1   (9.96e11 > 3.03e10)
```

|---|---|
| `D0 = Vref/Vin` | 0.250000 |
| `I0 = Vref/R` | 2.0000 A |
| 输入功率 `Vin·D0·I0` | 24.0000 W |
| 输出功率 `Vref·I0` | 24.0000 W |
| **功率平衡误差** | **0.000e+00 W** |

### 2.4 内环到底在调什么（ff 的结构性作用）

| | ff = 0 | ff = 1 |
|---|---|---|
| `iLref` | `Kp_e·e + Ki_e·xe` | `Kp_e·e + Ki_e·xe + iLoad` |
| 电流误差 | `iLref − iL` | `Kp_e·e + Ki_e·xe − (iL − iLoad)` = `… − iC` |
| 内环调节量 | **电感电流** | **电容电流** |
| 外环看到的对象 | `R/(1+sRC)` 带 LC 谐振 | ≈`1/(Cs)`（谐振从外环消失） |
| 外环特征方程（`Kci→∞`） | `RC·s² + (1+R·Kp_e)s + R·Ki_e = 0` | `C·s² + Kp_e·s + Ki_e = 0` |
| `ζ` | `(1+R·Kp_e)/(2R√(C·Ki_e))` | `Kp_e/(2√(C·Ki_e))` |

**这一条解释了为什么 ff=1 的效果远大于"前馈一点点电流"**：
它不是把扰动前馈掉，而是把**外环的受控对象换掉了**。

### 2.5 连续 vs 离散：模型差异的定量

| 项 | 连续 | 离散（ZOH + 1 拍计算延迟） |
|---|---|---|
| 电流环极点 | `−Kci/L` | `z = 1 − Kci·Ts/L` |
| 外环附加相位滞后 | 0 | `−ω·1.5·Ts` |
| 可靠区间 | 任意 `Kci` | **`Kci ≤ L/Ts = 7.5 Ω`** |

`−ω·1.5·Ts` 在 `fc = fs/3 = 16.7 kHz` 处就是 **180°**——所以
**`fs/3` 绝对不能当安全带宽**（见 §3.2 的量化表）。

## 3. Task 2：电流内环设计

### 3.1 电流闭环传递函数

内环对象是 `iL/d = Vin/(L·s)`（一个纯积分器），比例内环 `Kci/Vin` 闭合后：

```
iL / iLref = Kci / (L·s + Kci)        —— 一阶，DC 增益 1，无过冲
τ_i = L/Kci        f_-3dB = Kci/(2πL)        10-90% 上升时间 = 2.2·τ_i
```

| `Kci` (Ω) | `τ_i` (µs) | 上升时间 (µs) | `f_-3dB` (Hz) | `f_-3dB/fs` | 过冲 (%) |
|---|---|---|---|---|---|
| 0.63（3A.3 的理论起点） | 238.1 | 523.1 | 668.5 | 0.013 | **0** |
| 1.0 | 150.0 | 329.6 | 1061.0 | 0.021 | 0 |
| 1.5 | 100.0 | 219.7 | 1591.5 | 0.032 | 0 |
| 2.0 | 75.0 | 164.8 | 2122.1 | 0.042 | 0 |
| 3.0 | 50.0 | 109.9 | 3183.1 | 0.064 | 0 |
| 5.0 | 30.0 | 65.9 | 5305.2 | 0.106 | 0 |
| 8.0 | 18.8 | 41.2 | 8488.3 | 0.170 | 0 |
| 12.0 | 12.5 | 27.5 | 12732.4 | 0.255 | 0 |

**一阶系统没有过冲**，所以"电流跟踪过冲"这一项天然为 0；要担心的是**采样带来的 fs/2 振荡**（§3.3）。

### 3.2 延迟代价的量化（为什么 `fs/3` 不是安全带宽）

采样 + 零阶保持 + 一拍计算延迟 ≈ **1.5·Ts** 的等效延迟。相位滞后 = `ω·1.5·Ts`：

| 交越频率 | 0.5·Ts | 1·Ts | **1.5·Ts** | 2·Ts |
|---|---|---|---|---|
| 500 Hz | 1.8° | 3.6° | **5.4°** | 7.2° |
| 1 kHz | 3.6° | 7.2° | **10.8°** | 14.4° |
| 2 kHz | 7.2° | 14.4° | **21.6°** | 28.8° |
| 4 kHz | 14.4° | 28.8° | **43.2°** | 57.6° |
| **fs/3 = 16.67 kHz** | 60° | **120°** | **180°** | 240° |
| fs/2 = 25 kHz | 90° | 180° | 270° | 360° |

**在 `fc = fs/3` 处，单拍延迟就是 120°，加上 ZOH 是 180° —— 相位裕度为 0。**
所以 3A.2 里写的"`Kci ≤ 2πL·fs/3` 且带宽余量 8~15 倍"这个判断是**错的**：
它只看了连续模型的增益，没看延迟相位。本轮的可行 `Kci` 上限由 §3.3 的采样约束决定，**不是** `fs/3`。

### 3.3 内环采样约束（本轮最重要的工程发现之一）

数字内环闭合在积分器上，比例增益 `Kci` 使电流环极点映射到

```
z_inner = 1 − Kci·Ts/L
```

| `Kci` | `z_inner` | 物理表现 |
|---|---|---|
| 2 | 0.733 | 一阶衰减，最好 |
| 5 | 0.333 | 轻微振铃 |
| **7.5 = L/Ts** | **0** | 临界 |
| 8 | −0.067 | 在 fs/2 附近有极轻的振铃（实测仍可用） |
| 10 | −0.333 | 可见 fs/2 振荡 |
| 12 | −0.600 | **不收敛** |
| 15 | −1.000 | 不稳定边界 |
| 20 | −1.667 | 发散 |

**实测证据**（`verify/buck_a4_probe_disc.m` 与 `.tmpchk/qcheck`，C7 工况，Kp_e=1.8）：

| `Kci` | 线性模态和预测 S5 | **数字仿真实测 S5** | 结论 |
|---|---|---|---|
| 8.0 | 0.708 ms | 0.720 ms | 吻合，可信 |
| 10.0 | 0.718 ms | **NaN（30 ms 内不收敛）** | **线性模型完全失效** |
| 12.0 | 0.726 ms | **NaN** | 同上 |

这是本轮**代价最大的一次返工**：第一版可行域搜索完全基于连续模型，给出了
14 个"可行点"，全部落在 `Kci = 10~12`；用数字仿真一验，**一个都不成立**。
现在 `z_inner ≥ 0` 是硬约束（§5.1）。

### 3.4 占空比限幅与电流爬升能力

`d = Vref/Vin + Kci·(iLref−iL)/Vin`，撞到 `Dmax=0.85` 所需的电流误差：

```
(iLref − iL)|@Dmax = (Dmax − Vref/Vin)·Vin/Kci = 28.8/Kci   [A]
```

| `Kci` | 1 | 2 | 3 | 5 | 8 | 12 |
|---|---|---|---|---|---|---|
| 撞限幅所需误差 (A) | 28.8 | 14.4 | 9.6 | 5.76 | 3.6 | 2.4 |
| 撞限幅后的最大电流斜率 (A/s) | 192000 | 192000 | 192000 | 192000 | 192000 | 192000 |

斜率上限由 `(Vin·Dmax − vC)/L = (40.8−12)/150µ = 1.92e5 A/s` 决定，**与 Kci 无关**；
`Kci` 决定的是"多小的电流误差就能拿到这个斜率"。
这就是 S7（跌落）的杠杆：`Kci` 越大，跌落越浅 —— 但受 §3.3 约束，`Kci` 不能大。
**S5 与 S7 在这条轴上是同向的，真正的对撞来自外环增益与 PM。**

### 3.5 内环鲁棒性

内环极点 `−Kci/L` 随 L 线性移动。`L +30%`（C7，195 µH）使 `τ_i` 变为 1.30 倍：

| `Kci` | L=150 µH 极点 | L=195 µH 极点 | `τ_i` 变化 |
|---|---|---|---|
| 2 | −13333 | −10256 | 75.0 → 97.5 µs |
| 5 | −33333 | −25641 | 30.0 → 39.0 µs |
| 8 | −53333 | −41026 | 18.8 → 24.4 µs |

内环对 `L` 的偏差**只是变慢，不会失稳**（一阶，任何 `Kci>0` 都稳定）；
对 Vin、R 完全不敏感（内环不含这两个量）。真正的风险是 §3.3 的采样约束在
`L` **变小**时收紧 —— 本工况集里 L 只增大，所以是安全方向。

## 4. Task 3：电压外环设计

### 4.1 设计公式（只用于取初值，不作证据）

| | ff = 0 | ff = 1 |

| `Kci → ∞` 极限特征方程 | `RC·s² + (1+R·Kp_e)·s + R·Ki_e = 0` | `C·s² + Kp_e·s + Ki_e = 0` |
| `ωn` | `√(Ki_e/C)` | `√(Ki_e/C)` |

### 4.2 启动超调

外环积分器从 0 起、`vC` 从 0 起启动，占空比在启动段必然贴上限（`0.85`）——
这是任何 Buck 从零启动的正常行为，也是 S6 用"启动段最大超调"而不是"启动段占空比"考核的原因。
本轮四个控制器都在同一个 `X0=[0;0]` 下启动，S6 在 §6 的矩阵中如实报告。

### 4.3 负载阶跃时外环能否快速抬高电流指令

这是 S5/S7 的核心机理，用**阶跃瞬间的电流指令增量**衡量：

| | ff = 0 | ff = 1 |
|---|---|---|
| 阶跃瞬间 `e` | 0（`vC` 连续） | 0 |
| 阶跃瞬间 `iLref` 增量 | `Kp_e·e + Ki_e·xe` 的变化 ≈ **0** | **`ΔiLoad` = 2 A（立刻）** |
| 之后靠什么涨 | `e` 随 vC 下跌而增大 → `Kp_e·e` 缓慢建立 | 已到位，内环直接跟 |
| 实测跌落（C1） | −6.573% | **−1.195%** |

**这是 ff 的真正价值：它把"等误差长出来再反应"变成"阶跃当场就反应"。**
纯双环的跌落只能靠 `Kp_e` 大来压，而 `Kp_e` 大 → 交越频率高 → 被 §3.2 的延迟卡住。

### 4.4 负载电流前馈的条件、成本与假设

| 项 | 内容 |
|---|---|
| 需要的信号 | 负载电流 `iLoad`（或电容电流 `iC`，两者差一个 `iL`） |
| 硬件 | 1 路电流采样：分流电阻 + 差分放大，或霍尔传感器；**1 个额外 ADC 通道** |
| 成本量级 | 分流器方案 ≈ 0.1~0.3 元（BOM）；霍尔 ≈ 5~15 元 |
| 带宽要求 | 前馈路径只需覆盖外环带宽（本设计 ≈ 1 kHz），远低于开关频率 |
| 模型假设 | 在**小信号模型**里用 `iLoad = vC/R` 做线性化（因为 R 在阶跃处变化）；**实现里必须用实测 iLoad**，不能用 `vC/R`（R 未知且会变） |
| 失效模式 | 传感器增益误差 → 稳态误差 → **由外环积分器自动补偿**（这是本结构的优点：前馈只负责动态） |
| 是否可以不用传感器 | 理论上可用 `iC = C·dvC/dt` 差分估计，但阶跃瞬间正是最需要它的时候，差分的相位滞后最大，本轮**未采用也未验证** |

> 诚实说明：本节的前馈结论来自**理想 iLoad 测量**的模型与 Simulink 仿真。
> 传感器的噪声、带宽、失调**没有建模**。工程化时必须补这一项。

### 4.5 抗饱和与软启动（两个必须披露的设计改动）

双环的失败项只有 S6（启动超调 25~36%），根因和处置如下。

**(a) 抗饱和增益 `1/Tt` 必须随前向增益缩放。**
3A.2 的控制器是 `Ki=7.9`，`Tt=1 ms`（`1/Tt=1000`）。双环的 `Ki_e=4000~5500`，
前向增益大 **700 倍**，同样的 `1/Tt` 完全拉不住积分器：

```
启动时 e = 12 V，Ki_e·e = 48~66 kA/s
抗饱和项 = (1/Tt)·[(dSat−dRaw)·Vin/Kci + (iLref_lim − iLref_raw)]
         = 1000 × (−16.8 A) ≈ −16.8 kA/s      ← 只有前向项的一半
净积分速度 ≈ +31 kA/s > 0  ⇒ 积分器继续卷
```

`Tt` 扫描（`Tt: 1ms → 20µs`）把启动超调从 72% 压到 7.5%，但**仍达不到 5%**。

**(b) 真正的根因是"启动瞬态比外环带宽还快"。**
从 `vC=0` 充电到 12 V 只需约 0.3 ms，而外环闭环时间常数约 0.5 ms。
控制器还没反应过来，输出已经到了，积分器只能单调累积 → 超调。
这是**结构性的**，调 `Tt` 无法解决。

**处置：软启动 + 误差钳位。**

| 措施 | 参数 | 作用 |
|---|---|---|
| 软启动 | `Tss = 5 ms`（参考 0→12 V 线性斜坡） | 把"快的瞬态"换成"慢的参考"，让外环跟得上 |
| 误差钳位 | `Eclamp = 1.5 V` | 限制 `Kp_e·12 = 21.6 A` 的荒谬过指令 |
| 抗饱和 | `Tt = 0.3 ms` | 与新的前向增益匹配 |
| 电流指令限幅 | `Imax = 12 A` | 最大负载 8 A 的 1.5 倍，安全的物理上限 |

**软启动是否影响负载阶跃？不影响。** 负载阶跃时 `|e| ≤ 1.5 V < Eclamp`，
且 `Tss` 只在 `t<5 ms` 起作用（阶跃在 60 ms）。实测验证（`Tss` 扫描）：

| `Tss` | 启动超调 @6Ω | @3Ω | @12Ω | 跌落% | S5 (ms) |
|---|---|---|---|---|---|
| 0（无软启动） | 11.27 | 11.01 | 12.06 | −2.317 | 0.1400 |
| 2 ms | 3.22 | 3.25 | 3.18 | −2.317 | 0.1400 |
| **5 ms（定稿）** | **1.29** | **1.32** | **1.28** | **−2.317** | **0.1400** |
| 10 ms | 0.65 | 0.66 | 0.64 | −2.317 | 0.1400 |

**软启动不是"放宽标准"**：S6 的阈值仍是 5%，只是把"12 V 阶跃"改成了"5 ms 斜坡"这种
标准工程做法（每一颗量产 Buck 控制器都有软启动）。**但必须承认**：
BASE/OPT 是在**没有软启动**的条件下通过 S6 的（0.13%/−0.24%），
双环需要软启动才能通过。这个不对称已如实记录，且 §6 的矩阵中四个控制器的软启动设置
并未统一——BASE/OPT 保持历史配置不变，避免为了"公平"去改动已验证的历史结果。

### 5.5 CAND-A 的跌落为什么只能到 −11.3%（预测 −11.8%）

CAND-A 的 `Kci=7`，撞到 `Dmax` 需要 4.1 A 的电流误差；
而 `Kp_e=1.6` 在跌落 11.3%（1.36 V，§6 实测）时只给出 2.27 A 的指令增量。
**电流爬升速度不够快 ⇒ 电容放电多 ⇒ 跌落深 ⇒ S5 长。**
想加深跌落恢复只能加大 `Kp_e`（→ 交越上升 → 被延迟卡住 PM）或加大 `Kci`（→ 被采样约束卡住）。
两端都被堵住，这就是 CAND-A 只能卡在边界的原因。

| CAND-A | −11.77% | 30× |
| **CAND-B** | **−2.72%（C5/C6），−1.40%（C1）** | **0.82× / 3.6×** |

CAND-B 在 C5/C6 上已经达到物理下界的 82% —— **S7 已基本触底，没有继续优化的空间**。

### 7.3 错误、重试与最终处置（完整清单，不挑好看的）

| # | 错误 | 怎么发现的 | 处置 |
|---|---|---|---|
| 1 | `iL_err` 接到了"饱和差值"而不是"限幅后的电流指令" | Simulink 启动后 vC 停在 **2.4 V**（= `Vin·Dmin`），duty 恒为 0.25 | 改接线；加注释说明 `iL_satdiff` 只能用于抗饱和 |
| 2 | 模型名与脚本同名 | Simulink 报 shadowing 警告 | 模型名加后缀 |
| 3 | `vC/iLref` 传函漏了负载反馈项（`+R`） | 算出的 PM **> 90°**（不可能这么好）；DC 增益是 `R` 而不是 `R·Kci/(Kci+R)` | 重推 2 状态传函，加 DC 增益自检（不符就 error） |
| 4 | 前馈改变了被控对象结构，却仍用 ff=0 的传函算 PM | 前馈时 PM 与 S5 的 Pareto 反常地好 | 新写 `dual_loop_gain.m`，从状态方程重推 |
| 5 | 模态分解的初值 `xe=0`（应为 `(Vref/R0)/Ki_e`） | 初始偏差算出 **31.8%**，物理上不可能 | 修初值；加注释 |
| 6 | S5 频带写成 `0.12*Vref`（应为 `0.01*Vref`） | 跌落 −11.8% 却算出 **S5=0** | 修；这类"结果自相矛盾"是最快的错误信号 |
| 7 | 可行域搜索的 RA/RB 标签互换 | 两栏数字与前一版正好对调 | 修 |
| 8 | 结构体预分配缺 `zInner` 字段 | MATLAB 报"在不同结构体之间进行下标赋值" | 补齐字段 |
| 9 | **连续模型在 `Kci ≥ 10` 完全失效** | 数字仿真 S5 = `NaN`（不收敛），而线性模型给 0.72 ms | **加 `z_inner ≥ 0` 硬约束，整个搜索重做**（代价最大的一次） |
| 10 | 抗饱和 `1/Tt` 沿用 3A.2 的 1 ms | 启动超调 **25~36%**，而 3A.2 的控制器同参数下是 0.13% | 分析出前向增益差 700 倍，`1/Tt` 必须重定；扫 `Tt` 后仍不够 |
| 11 | 启动超调即使 `Tt` 优化后仍 10~14% | 发现充电瞬态（0.3 ms）比外环带宽（0.5 ms）还快 | 加**软启动**（`Tss=5 ms`）+ 误差钳位；Simulink 复验启动超调 **1.41%** |
| 12 | 回归脚本从不累加 `nFail` | 打出"9 通过 / 0 失败 / 共 9 项" | 改独立 `nAssert` 计数 |
| 13 | 测试断言 S7c 自己写错（`nExits` 期望 1，实为 0） | 断言 FAIL 但汇总说 9/0 | 修正断言并说明理由（该越界在首次进入之前） |
| 14 | `load()` 返回值多包一层（`S.S.A`） | "无法识别的字段名称 A" | 取 `.S` |
| 15 | 工况结构体缺 `C` 字段 | "无法识别的字段名称 C" | 补齐 |

**其中 #9、#10、#11 是"结论级"的**：它们分别改变了可行域、暴露了抗饱和设计缺陷、
并迫使增加一个标准的工程措施（软启动）。其余是接线/编码级。
